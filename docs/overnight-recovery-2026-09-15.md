## Root causes and changes

The supervisor delayed idle turns but still invoked the model when the delay
expired. The lead's saved cursor also advanced to the end of the turn, swallowing
sources collected while it reasoned. Model admission now uses the durable input
cursor, new evidence or operational feedback, queued work and agent-selected
reviews. Maintenance polls without purchasing a model turn. A successful turn
acknowledges the evidence available at its start. New arrivals survive restart.

Pi's `agent_end` reports the end of an underlying attempt. Its session can still
compact and retry afterward. CURI used to close the worker on that notification.
The unattended host now uses Pi's public SDK and acknowledges a prompt only after
the full `session.prompt` operation settles. Compaction and its continuation stay
inside the same inference lease and research run. Cancellation also aborts
compaction. Persistent sessions and executor transcripts remain on disk.

All oversized textual tool results now return a preview and a content-addressed
file in the assigned workspace. The full original is retained for targeted reads,
search, compaction recovery and handoff. This applies to full state, searches,
documents and checks. Display size and context reserves are transport limits;
they impose no study deadline, trial count or scientific report schema.

The first live wake identified another source of context inflation: its evidence
standards section replayed roughly 137 KB of historical validation arrays. It now
describes the canonical records, report integrity, execution diagnostics and
limitations in concise prose, with original reports retained in sealed handoffs.
Changed evidence, returned work and runtime feedback precede portfolio background.
The production record measured 6,199 bytes for the new evidence summary, compared
with 136,595 bytes for that section of the preceding live wake.

The live lead also staged a delegation and kept polling its fixed state snapshot
for a researcher that could not start while the lead held the slot. Delegation is
now an explicit turn handoff: the SDK host finishes the current tool batch and
yields before another model request. The supervisor still validates staged actions
before queuing work. This follows the lead's chosen delegation and imposes no
study duration. Tool descriptions now distinguish staged actions from running work.

Research records are no longer silently cut at 30,000/60,000 characters in search.
Large source excerpts retain an explicit path to the full staged original, keeping
the disposable source index bounded without concealing how to read omitted text.

Discovery uses the existing durable watcher cursors for exponential failure
backoff, across subscriptions and discovered documents. Provider Retry-After
cooldowns persist by host, including across restarts and requests to other URLs.
Cooldowns release the watcher to work on other sources. Repeated transient failures
do not create repeated evidence events. Robots denial or an HTML challenge blocks
collection until access can be inspected; neither permits bypassing restrictions.
Refreshing an existing source preserves its watch and parser settings when those
arguments are omitted. An explicit follow=false still ends that subscription.

The lead instructions distinguish an incumbent's paper wait from independent
research. The book now labels the selected checkpoint accurately. An issuer case
can use archived filings and remain discovery evidence without an executable
strategy, a forced forecast, or a change to portfolio risk limits.
