# Literature Review

The presentation concentrates on navigation. The full review covers navigation, target tracking, exploration, model foundations, and evidence limits.

The revised presentation and reviews distinguish technical results from mission value. They test complex navigation against planned overflight and other simple mission designs, give each paper a plausible use and an evidence limit, and correct the city-scale gap claim using the real SPRIN-D competition flights. Historical proposals remain research ideas until a specific mission and baseline failure justify them.
