# UAV model research and development

Develop an implementable learned system for one primary use case: an onboard quadrotor navigating through cluttered, partially observed 3D environments to reach sequential visual waypoints while the vehicle is moving and inference is delayed. Tracking and exploration are future branches; they are not simultaneous objectives for the next study. Use the revised Handoff in .research-guidance/HANDOFF.md and the current scientific contract.

The objective is an actual learned architecture in a functioning sensory, predictive and control system. The environment is part of the research foundation: it must contain continuous vehicle motion, 3D geometry, occlusion, textures/lighting, collision and braking consequences, and a clear sensor/latency envelope. A model cannot be judged on a toy scene that removes the problem it is meant to solve. An isolated heuristic or low-dimensional surrogate is not the research product.

Build one persistent implementation lineage using an established simulator, public real-scene reconstruction, or a defensible real-to-sim asset, plus primary literature and released code. First make the chosen environment and data path visibly support the use case; do not train a new model on the current five-scene primitive world. Then develop an explicit model or system change with strong comparisons. Carry unfinished integration across tasks and retain checkpoints. Published papers enrich development and constrain originality.

Evaluate actual camera observations, vehicle dynamics, inference-time motion, latency/speed tradeoffs, occlusion, collision, route progress and held-out scenes. The first environment milestone must include a rendered-flight visualization and executable route/collision metrics before model training is resumed. Preserve the 60% local VRAM limit. Use the configured Spark research pipeline. No physical flight or new expenditure. The current research epoch replaces earlier heuristic queues and broad rejection summaries; papers and scoped historical artifacts remain accessible.
