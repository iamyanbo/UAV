| Candidate | What changes in the implementation | First useful outcome |
|---|---|---|
| [1. How long can this maneuver remain valid?](01-action-validity-horizon.md) | Train a small head to predict candidate-specific safe commitment duration under delayed reasoning; choose both the maneuver and when to stop trusting it. | Test whether the learned distribution beats an ordinary adaptive chunk-length head and a geometric deadline rule. |
| [2. A JEPA that remembers escape options](02-recoverability-jepa.md) | Train the predictive representation to preserve which braking/turning options remain feasible in future states. | Test whether this training objective helps beyond adding a safety head to an unchanged world model. |

The first is easiest to prototype with a small local model. The second changes a training objective rather than merely comparing JEPA variants. The third is closest to the user's rapid world-building idea, but has the greatest scene-tooling risk. All three have strong adjacent prior art. A negative novelty verdict is a useful result; none is labelled "confirmed novel."

## How these enter the existing pipeline

The importer uses the existing investigation ledger and active investigation plans. It does not create executor processes, bypass preflight, change models, replace the orchestrator, or install a special overnight loop. Existing work remains in front of the new plans. The ordinary supervisor dispatches one investigation when the existing handoff is resolved; the Spark lead interprets its result and decides closure or a genuinely new follow-up. After these finite plans are handled, ordinary Spark research continues. Continuous mode is the existing runtime setting, not a new scheduler.

Each recorded investigation includes its full card and the [shared execution contract](execution-contract.md), so the isolated worker receives the details even if these new repository files have not been committed. The importer is safe to rerun: an unchanged recorded case is reused, and an existing plan is never reopened or overwritten by a repeated import.

From the repository root:

```powershell
node --import tsx scripts/inject-uav-ideas.ts
node --import tsx scripts/inject-uav-ideas.ts --apply
node --import tsx src/cli.ts research continuous --direction uav-navigation
```

The first command only validates and previews. The second injects the candidates. The last enables normal ongoing research; it does not restart the running worker. No promise is made that all experiments finish overnight: dependency failures, novelty rejection, and the running task's duration matter.

## Literature boundary and unresolved checks

The seed review used primary arXiv records, available HTML, and author/publisher project results on 2026-09-19. Query families included real-time correction, adaptive action chunking and execution horizons, JEPA recoverability and action-based representations, and Gaussian-splatting active perception and policy regret. This is a targeted collision screen, not an exhaustive review. An abstract or search result is not evidence that an implementation lacks a feature. The worker must retrieve full methods/supplements and follow citations in both directions.

Particularly important late collisions are [DEHP](https://arxiv.org/abs/2606.11408), which already learns execution horizons; [Calibrated Predictive Safety](https://arxiv.org/abs/2608.17496), which already combines candidate-action JEPA rollouts with risk scoring and shields; and [SemSafe-3DGS](https://arxiv.org/abs/2609.19330), which already combines semantic safety with trajectory-relevant active perception. The proposed differences must survive comparison to these, not merely comparison to a generic VLM baseline.

Additional discovery leads requiring method-level retrieval include [AAC, CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/papers/Liang_Adaptive_Action_Chunking_at_Inference-time_for_Vision-Language-Action_Models_CVPR_2026_paper.pdf), [AutoHorizon](https://hatchetproject.github.io/autohorizon/), [PSG-JEPA](https://haodong-yan.github.io/psg-jepa-project-page/), and [EmbodiedSplat, ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/papers/Chhablani_EmbodiedSplat_Personalized_Real-to-Sim-to-Real_Navigation_with_Gaussian_Splats_from_a_Mobile_ICCV_2025_paper.pdf). Their inclusion is a search obligation, not a claim that their full implementation was audited during injection.

The original research-ideas document is not replaced. These are a separately dated, attributable expansion and can be dropped without rewriting the user's research direction.
